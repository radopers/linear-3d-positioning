The central idea

Deliberately keep less information

Let P be the unknown point. We know the coordinates of the anchors M₁, M₂, … and the distance rᵢ from each anchor Mᵢ to P. All coordinates and distances use the same unit.

Two exact distances, r₁ and r₂, usually restrict P to a circle: the intersection of the two distance spheres. The circle is perpendicular to the line M₁M₂.

Replace “P is on this circle” with the weaker condition “P is in this plane.” We discard the condition that P must be exactly one circle radius from the circle's center. The retained plane constraint is linear in x, y, and z.

For one anchor pair this allows many extra positions. The useful result comes from combining several such weaker constraints. Three independent planes have just one common point. If the distances are exact and consistent, the true P is on every original circle and therefore in every constructed plane.

Nothing requires these planes to be mutually perpendicular. Each plane is perpendicular only to its own anchor-to-anchor baseline.

The construction in one view

  1. Use the two right triangles to find the circle center Pₖ on M₁M₂.
  2. Normalize the vector M₁M₂ to get the plane coefficients a, b, c.
  3. Insert the known point Pₖ into the plane equation to get d.
  4. Repeat for M₁M₃ and M₁M₄, then solve the three plane equations.
  5. With additional planes, minimize the sum of squared point-to-plane distances. Its three coordinate derivatives give another 3 × 3 linear system.

The drawings use one general spatial arrangement throughout. In that example none of the three baselines is perpendicular to another, and none is aligned with a coordinate axis.

Step 1 · Two right triangles

Find the fraction k along the baseline

Call the distance between M₁ and M₂ L = ‖M₂ − M₁‖. Let Pₖ be the center of the intersection circle. It lies on the baseline. Write its signed distance from M₁ as kL; the remaining signed distance to M₂ is (1 − k)L.

The segment PₖP is perpendicular to the baseline and has the circle radius h. This makes two right triangles, M₁–Pₖ–P and M₂–Pₖ–P.

Apply Pythagoras separately to the two triangles:

h² = r₁² − (kL)²h² = r₂² − ((1 − k)L)²

Both expressions describe the same h², so set them equal:

r₁² − k²L² = r₂² − (1 − 2k + k²)L²2kL² = L² + r₁² − r₂²

Everything except k is already known. Therefore,

k = L² + r₁² − r₂²2L² = 12 − r₂² − r₁²2L²The shared circle radius h has been eliminated. We never need to calculate it.

The picture shows 0 < k < 1. The same equations also work when Pₖ lies on the baseline's extension, so k can be negative or greater than 1. The two anchor positions must be distinct: L ≠ 0.

Step 2 · A known point in the plane

Calculate the coordinates of Pₖ

Start at M₁ and move by k times the displacement vector from M₁ to M₂:

Pk = M1 + k(M2 − M1)
Pkx = M1x + k(M2x − M1x)Pky = M1y + k(M2y − M1y)Pkz = M1z + k(M2z − M1z)

Pₖ is the center of the circle, so it is also a point in the plane we want to construct.

Step 3 · The orientation of the plane

The baseline gives a, b, and c

The plane is perpendicular to M₁M₂. Its normal therefore points along M₂ − M₁. Normalize this vector by dividing by its length L:

n = (a, b, c) = M2 − M1L
a = M2x − M1xL,   b = M2y − M1yL,   c = M2z − M1zLThus a² + b² + c² = 1.

These are already the first three coefficients of the plane equation

ax + by + cz + d = 0.

Only d remains unknown.

Step 4 · The position of the plane

Insert Pₖ to find d

Because the known point Pₖ lies in the plane, its coordinates must make the plane equation zero:

aPkx + bPky + cPkz + d = 0
d = −(aPkx + bPky + cPkz)

All four coefficients are now known. We have constructed one linear equation for the unknown coordinates of P:

ax + by + cz + d = 0The plane containing the M₁–M₂ circle. The circle-radius condition is no longer imposed.

Since the normal is a unit vector, ax + by + cz + d is also the signed perpendicular distance from any point (x, y, z) to this plane. Points in the plane have distance zero.

Step 5 · Combine the planes

Repeat twice, then solve three equations

Keep M₁ as the reference and repeat the same construction for M₁–M₃ and M₁–M₄. Let E₂, E₃, and E₄ denote the three planes. The subscript identifies the other anchor in the pair.

The three pictures use the same camera and the same general anchor arrangement. The planes are oblique to one another. The requirement is that their normals are linearly independent, not orthogonal. For four anchors, this means the anchor positions are not all in one plane.

P must make each plane equation zero:

a₂x + b₂y + c₂z = −d₂a₃x + b₃y + c₃z = −d₃a₄x + b₄y + c₄z = −d₄
a₂b₂c₂a₃b₃c₃a₄b₄c₄xyz=−d₂−d₃−d₄

This is an ordinary linear system Ap = b. Solve it with Gaussian elimination, QR, or another linear-system solver.

Step 6 · Additional anchors

Minimize the squared distances to all planes

Each additional anchor gives another plane by the same construction. With exact, consistent distances, all the planes contain P. With rounded or noisy distances, they generally do not share a single point.

For a trial position P = (x, y, z), its signed distance to normalized plane Eᵢ is

eᵢ = aᵢx + bᵢy + cᵢz + dᵢ.

Minimize the sum of squared plane distances, optionally with nonnegative weights wᵢ:

E(x, y, z) = ∑i=2N wᵢ(aᵢx + bᵢy + cᵢz + dᵢ)².Use wᵢ = 1 for an unweighted sum. A zero weight omits a plane.

Differentiate with respect to the three unknown coordinates and set the derivatives to zero:

∂E/∂x = 2∑ wᵢaᵢ(aᵢx + bᵢy + cᵢz + dᵢ) = 0∂E/∂y = 2∑ wᵢbᵢ(aᵢx + bᵢy + cᵢz + dᵢ) = 0∂E/∂z = 2∑ wᵢcᵢ(aᵢx + bᵢy + cᵢz + dᵢ) = 0

Expand, collect x, y, and z, and divide by 2:

(∑wa²)x + (∑wab)y + (∑wac)z = −∑wad(∑wab)x + (∑wb²)y + (∑wbc)z = −∑wbd(∑wac)x + (∑wbc)y + (∑wc²)z = −∑wcdAll sums run over the constructed planes; the subscripts i have been suppressed.
∑wa²∑wab∑wac∑wab∑wb²∑wbc∑wac∑wbc∑wc²xyz=−∑wad−∑wbd−∑wcd

However many planes are included, there are still exactly three equations in three unknowns. Solve this linear system by Gaussian elimination, QR, or another linear-system solver. When the positively weighted normals span 3D, its solution is the unique minimum of the squared plane-distance sum.

Keep the plane normals normalized when forming this error sum. Rescaling a plane equation would otherwise change its contribution even though the plane itself has not moved.

What the discarded information costs

Why four anchors?

For this construction, three anchors give two planes. Their intersection is generally a line. A fourth anchor provides the third independent plane and fixes a point on that line.

If we kept the full distance constraints, three exact ranges to noncollinear anchors would generally leave two points, mirrored across the plane through those three anchors. Additional information can select one of them. A fourth noncoplanar anchor normally removes that ambiguity. Thus four anchors are also the usual requirement for a unique, unconstrained geometric solution in 3D; they are not generally an extra anchor required only by this construction.

The relaxation is visible with three anchors: the full constraints leave at most two points, while the two planes alone leave a whole line. With four noncoplanar anchors and consistent exact ranges, the three planes reduce that freedom to the true point.

Actual GPS has an additional unknown. This paper assumes known geometric distances. Ordinary GNSS pseudoranges also contain a receiver clock offset, so the usual positioning problem solves three coordinates plus that clock offset. Its familiar four-satellite count should not be interpreted as a direct comparison with the three-coordinate construction here. See ESA Navipedia: Code Based Positioning.

Conditions and checks

The baselines must have nonzero length, and the retained plane normals must span three dimensions. Coplanar anchors do not determine a unique 3D point through these linear plane constraints. Nearly coplanar geometry can make the answer sensitive to small distance errors.

Because circle information was discarded, an intersection of planes from inconsistent inputs need not satisfy the original ranges. Recalculate the distances from the resulting point to the anchors when checking the measurements. The plane construction still gives algebraic planes if noisy range spheres fail to intersect, but then no actual intersection circle exists.

The original construction

The original November 2014 note

Roland Adorni’s original drawing in OldNotes/PointNET.svg already follows this construction: two right triangles, the factor k, the point Pk, the normalized baseline as the plane normal, and d obtained by inserting Pk. The Maxima worksheet then differentiates the weighted squared point-to-plane distance.

In the original notation, DM1 and DM2 are the ranges r₁ and r₂, DMM is the baseline length L, and Pk is the circle center Pₖ. Here h denotes the circle radius throughout.

The archived C# code extends the same idea to every anchor pair. Such planes can be included in the same three least-squares equations. They are derived from the existing measured ranges, rather than being new independent measurements. With noisy input, changing the set of pairs changes the plane-distance objective.
